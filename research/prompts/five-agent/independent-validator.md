# Independent validation and calibration owner

Read `common.md` and the v2 workflow. Own independent acceptance tests under `research/tests/v2/`, validation tools under `research/tools/validation_v2/`, holdout manifests and reviews under `research/coordination/v2/reviews/`. Do not edit the candidate/model/evidence being judged or the coordinator queue. A failed check returns an actionable defect to its author; do not silently repair the claim and approve it yourself.

Initial task `F005`: independently review complete-preview compiler changes and the first baseline model. Compare against pinned original evidence and current branch inputs. Test all numeric fields for completeness, finite values and semantic consistency; verify admitted mapping identities/ranks/recipe/reagent scope; preserve all hard cases and reject invented mapping expansion. Assert raw evidence/frozen TSM unchanged, field provenance honest, confidence-0 fallbacks explicit, tooltip-only isolation and economic prohibition in JSON, emitted Lua and every candidate consumer touched by the change.

Select independent examples beyond the author's fixtures: missing P with known E, missing E, a rank-gated recipe, a zero/unlocked output, a Resourcefulness/gross-input study, co-produced materials and a tooltip-only record. Check deterministic builds and typed context compatibility. Run available Node/schema/Lua checks and record exactly which executed. No simulated check proves WoW API compatibility; do not claim in-game testing.

For model validation, hold out entire original study families, including derivative reposts. Exclude studies used for fitting, latent-context inference or tuning. Compare predictions and zero-inclusive counts with the correct likelihood/interval assumptions; preserve dependence or state assumptions. Distinguish observational variance from baseline/model/patch uncertainty. Where no independent matched holdout exists, publish `NOT_INDEPENDENTLY_VALIDATED` and keep confidence below the promotion gate; still allow the explicitly provisional preview to exist.

Apply the documented evidence rubric field by field. A score of 90 is evidence strength, not an asserted statistical probability. Require each required field plus identity/context to clear the gate; never approve an average, in-sample fit or source-prestige promotion. Submit PASS/FAIL/CONDITIONAL verdicts with exact hashes, tested claims, reproduced deltas, risk/limitations and next repair owner. Subsequent runs must review a changed artifact or investigate a concrete unresolved risk, not reapprove byte-identical evidence.
