Loot Liquidator currently chooses among several overlapping reference/scenario paths, including tooltip occurrence/range proxies inferred from average yields. This change makes a versioned compiled itemdb the primary reference, resolves compatible source evidence per output, and uses the same final model for tooltips and processing value. Unknown fields remain unknown; missing quantities/prices cannot create a complete recommendation.

All installable addon files now live in `LootLiquidator/`. Runtime Lua files decrease from 24 to 16 through observation/native-bank event dispatchers and shared profession/settings ownership. The compact character roster and its Manual checkboxes are retained; profession profiles are nested below Professions & Alts. Database & Accuracy provides native checkboxes and 0–100 sliders with defaults itemdb 100, personal 60, TSM references 30, legacy disabled/10. Existing SavedVariables migrate additively.

The compiler ships 267 schema-validated source records: 248 provisional references and 19 documented smelting recipes. New independently reviewed database releases do not require engine changes. PR #4's adapter/tests are retained. There are no approved numeric coefficients in the reviewed registry, so no live skill multiplier is shipped. Recipe/build/context-scoped numeric transforms, explicit simulations and offline snapshots are supported conservatively; unsupported transforms retain an unadjusted reference. The ongoing research branch is not merged.

Validation: `bash tests/run.sh` passes deterministic artifact reproduction, Lua 5.1 syntax, package/load-order/XML checks, the preserved mechanics fixtures, 2,602 modernization assertions and native settings interaction fixtures. Six unchanged integration/data files are byte-identical to the PR #4 baseline. A synthetic 10,000-lookup comparison is slower in the weighted path (~7.4 vs ~4.6 µs/call); no overall performance improvement is claimed. Distribution/context caches are bounded; market prices are refreshed at valuation.

In-game testing is pending. See `docs/retail-qa.md` for bags/banks, BetterBags, ATT/tokens, TSM operations, profile scanning, native settings skins and observation QA. Older unversioned observations remain saved/exportable but are not silently promoted to current-build character evidence. Deprecated scenario slider values are preserved but no longer apply unsupported coefficients. Missing output rank/patch context may correctly produce Insufficient Data. Discrete quality/eligibility transformations await independently validated formula implementations.

Detailed schema, weighting formula, file ownership, migration and limitations: `docs/modernization.md`.
