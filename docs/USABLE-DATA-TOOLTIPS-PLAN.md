- Average output quantities are optional and hidden by default; yield ranges omit x. Native Tooltips settings offer value, chance, average quantity, name and database-order sorting. Sorting does not mutate cached economic models.
- Provide before/after actual-engine and tooltip proofs, a complete known-gap disposition ledger, reproducible generated artifacts, passing required local and GitHub checks, and one reviewable PR against main. Clearly identify actual-client QA status. No unsupported claim of universal Retail coverage.
