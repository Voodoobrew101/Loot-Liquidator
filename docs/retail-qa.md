## Source, profile and candidate boundaries

Source controls are in **Database & Accuracy**. Defaults in `Database.lua` are 100/60/25/10/10 for built-in/personal/imported/legacy/reference. Slider weight is not confidence or a promised percentage of the final estimate. Check each source alone, disabled and zero-weight, reset, repeated unchanged slider updates, and reload. Source shares must describe evidence that actually contributed. Reference fallback must retain its lower-confidence label; it cannot manufacture missing rank probabilities.

Under **Database & Accuracy > Observation policy**, verify Weighted evidence / Personal observations only / External references only for Disenchanting, Milling, Prospecting and Other processing, as well as the source switches. Disabled switches and zero weights still apply within the selected mode. Personal observations only (mode 2) excludes every nonpersonal source even when its switch/weight is enabled; External references only (mode 3) excludes personal evidence. There is no built-in source-preset dropdown: use the individual switches/weights, policy controls and Reset source weights, rather than assuming a named preset changes eligibility.

Current measured context, saved offline scans and Simulated selections are different inputs. Test each with matching and mismatched build/rank/skill/equipment, stale scans and unavailable API fields. Unsupported modifiers or missing context must not become invented zeros or calibrated skill effects. A simulated display is not measured evidence. Do not infer that a successful current-character test establishes offline/simulated support.

Main's importer accepts Disenchant/Mill/Prospect/Smelt, not the two salvage contracts added by unmerged PR51. Main's broad Disenchant imports do not establish safe exact skill/context applicability; use controlled SavedVariables backups and do not promote them as validated calibration. PR54's held-import archive/status is also unmerged. Candidate-specific live import, codec and persistence tests remain open; testing one candidate does not verify another or their combination.
