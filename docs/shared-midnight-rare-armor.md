Midnight rare armor. The shared groups contain 544 Midnight rare-armor casts,

The importer uses the existing evidence compiler and confidence calculation.
These are observed category rates, not measurements at zero skill and not a
new inferred coefficient for skill, equipment or specialization. The measured
category reference takes precedence over older synthetic category scenarios;
it is not run through those zero-reference projections. Output-access gates
still run. These captures have no invested specialization. Explicit what-if
profiles and profiles with invested specialization continue to use the existing
simulation curves rather than asserting that these casts measured those
allocations. Source-profile precision and applicability to
an unmeasured profile are distinct uncertainties.

This limitation does not prevent the complete 544-cast category reference
from supporting estimates in the built-in database.

display fields keep their own uncertainty but cannot force that whole header
to zero. A model whose actual value confidence is zero still displays zero.
